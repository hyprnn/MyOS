# Сертификаты для автотеста HTTPS

Тестовый центр сертификации (`ca.pem`) и сертификат сервера
(`server.pem` + `server.key`, ключ ECDSA P-256, для адреса 10.0.2.2) —
на 100 лет. **Ключи НЕ секретные**: они нужны только `tools/autotest.py`,
который поднимает HTTPS-сервер на хосте; MyOS в QEMU проверяет его
сертификат через `wget --ca-certificate ca.pem`. Закрытый ключ самого
центра не сохранён — выпустить им что-то ещё нельзя.
