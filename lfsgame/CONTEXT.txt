 Book (side panel, F2; F3/F4 prev/next): TOC with progress marks, sections 0, 1.1,

6. KEY CONVENTIONS / APIs
 - Command: @command("name", "help", group, hidden=False, aliases=()) def fn(ctx, args).
   Return int/None, or be a generator: `yield Sleep(ms)`, `line = yield Input(prompt,
   secret=False)` (None = EOF/Ctrl+D), `return status`. Raise UsageError (status 2) or
   FsError (status 1); runner prints "name: message".
 - ctx: machine, game, history, write(text, tag), clear(), goto_menu(), save_game(),
   open_book(section_id|None) -> bool. Tags: dim err warn prompt ok accent dir link banner.
 - Machine methods raise FsError(reason); commands format messages like the real tools.
 - Objectives are sticky (Game.done); add new ones to OBJECTIVES with an existing book
   section id (a test checks it).
 - Book markup: @chapter, @section ID | Title, ##, $, >, !, -, blank line = paragraph.
   Every "$" line must parse and use a registered command (a test checks it).
 - Save: add fields => bump SAVE_VERSION + migrate in read_save.
 - Tk traps: handlers returning "break" stop propagation; F-keys must return None.
   Text tag bindings depend on the "current" mark (updated on Motion).
